# AgencyFlow CRM Dashboard

A modern and scalable CRM Dashboard UI designed for digital agencies, freelancers, and B2B service businesses to manage leads, clients, follow-ups, and internal tasks efficiently.

---

# 📌 Project Overview

This project was created as part of a UI/UX SaaS dashboard design task focused on solving real-world workflow management problems for agencies and startups.

Many small agencies still rely on:
- Spreadsheets
- WhatsApp messages
- Manual follow-ups
- Basic management tools

This creates:
- Missed follow-ups
- Poor organization
- Team confusion
- Lost client opportunities

AgencyFlow CRM provides a centralized dashboard solution to manage everything in one place.

---

# 🎯 Objective

The main goal of this project is to:

✅ Track leads across different stages  
✅ Manage active clients efficiently  
✅ Organize tasks and follow-ups  
✅ Improve team productivity  
✅ Create a scalable SaaS dashboard UI  
✅ Build a workflow-focused CRM experience  

---

# 🏢 Business Scenario

Designed for:

A 5-member digital marketing agency managing 30+ active clients and multiple sales leads.
